# 小安 · 本地数字人陪伴系统

面向老年陪伴场景的 Unity 数字人客户端与 Python 网关。当前产品只保留男性形象。

## 功能

- 中文语音对话、简体输出与对长辈的称呼约束。
- SenseVoice-Small 主识别，优先 CUDA、自动回退 CPU，保留降噪、VAD 和可选声纹验证。
- 受限指令同音纠错与多轮上下文；SenseVoice 不支持原生热词声学偏置。
- 本地提醒数据库，支持相对时间、修改、取消和时间到达后的提醒。
- 城市定位、天气查询与缓存；定位不是 GPS 精确定位。
- Unity VRM 角色、口型、表情、眯眼笑、阴影和上身交互动作。
- 网页文字与录音交互、请求超时和取消处理、语音缓存及音频完整性检查。

## 仓库内容

`gateway/`：Python 服务与业务模块；`unity-patches/`：当前客户端源码和上游工程集成补丁；`scripts/`：安装、模型准备、构建及验证；`face/`：历史照片特征工具；`config/`：不含个人数据的配置；`docs/`：UI 与交互说明。

这是完整的自研源码和集成脚本快照，**不是含全部第三方依赖的开箱即用安装包**。原机器约 52 GB 的模型、虚拟环境、原始 Unity 工程、个人数据和角色素材不在仓库中；旧开发 Git 历史也未公开。没有随仓库提供角色、参考声音或个人脸部档案，运行前需自行取得授权并准备。
