# 定位与天气

本功能直接查询天气服务，并生成中文结果；天气、位置和降水概率不交给语言模型猜测。Unity 主界面时钟下方显示城市、定位来源、天气、气温、今日高低温、最高降水概率。点击天气卡片可刷新。天气卡片下方的重新定位按钮框，以及来源和数据时间一行已按最新要求移除。

## 定位方式

首次天气查询没有已保存位置时，通过 HTTPS `ipwho.is` 估算网络出口的城市和坐标，再使用 Open-Meteo 地名查询获得中文名称。此方式不是 GPS，VPN、运营商出口和跨城网络可能造成偏差，界面明确标记“网络估算”。不支持街道级或持续 GPS 跟踪。

在文字或语音对话中说“定位到杭州市”“把位置设置为杭州”，可以保存所选城市；“我现在在哪里”会说明是网络估算还是手动设置。查询“上海明天天气”只查询上海，不修改当前城市。“重新定位”会将位置改回本次网络估算。

位置保存在 `config/location.json`，权限 0600，包含城市、坐标、时区、来源及更新时间，不保存 IP、街道或位置轨迹；此文件不纳入 Git。

## 天气与对话

Open-Meteo Forecast API 提供当前天气与未来三天预报。当前天气是服务提供的气象模型数据，不应理解为设备传感器测量或官方气象预警。天气代码通过 WMO 映射为中文。

可以问：“今天天气怎么样”“明天要带伞吗”“后天杭州会下雨吗”。支持现在、今天、明天、后天；其他日期明确提示支持范围。当前返回气温、体感温度、湿度、风速以及今日高低温和最高降水概率；未来日返回全天预报。雨雪或概率不低于 40% 时补充带伞和防滑建议。回答附带原始数据时间及来源。紧急求助与备忘提醒保持原有优先级。

服务端按坐标缓存十分钟。刷新可主动查询；网络失败时，仅在缓存不足一小时且日期仍匹配时返回，并明确标记“旧数据”。没有可用数据时显示失败提示，不编造数字。客户端每三十秒读取一次缓存，更新城市修改；自动定位不反复执行。天气数据缺失的响应不写入缓存。

## 接口

| 方法与路径 | 用途 |
| --- | --- |
| `GET /api/location` | 读取已保存位置，未设置返回 null |
| `POST /api/location/auto` | 重新网络定位并保存 |
| `PUT /api/location` | JSON `{"city":"杭州市"}`，解析城市并保存 |
| `GET /api/weather` | 获取当前位置天气，未定位时自动估算 |
| `GET /api/weather?city=上海` | 临时查询其他城市，不更改保存位置 |
| `GET /api/weather?refresh=true` | 主动刷新天气 |

配置无需云端模型密钥。外网定位与天气请求分别设置八秒超时。客户端录音与定位互不依赖，不使用麦克风推断位置。
